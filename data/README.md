# Data Layout

This project currently uses synthetic data only. No private company data is included.

## Files

- `data/synthetic/enterprise_knowledge_base.jsonl`: main local demo corpus generated by `scripts/generate_synthetic_data.py`.
- `data/synthetic/sample_documents.jsonl`: small hand-curated sample used by ingestion examples and tests.
- `data/processed/sample_chunks.jsonl`: processed chunk preview with deterministic local embeddings.
- `data/raw/`: placeholder for future raw PDFs, Markdown, CSV, JSON, or exported documents.
- `data/evaluation/`: placeholder for evaluation questions and expected source mappings.

## Regenerate Synthetic Data

```powershell
.\.venv\Scripts\python.exe scripts\generate_synthetic_data.py --output data\synthetic\enterprise_knowledge_base.jsonl
```

## Export Processed Chunks

```powershell
.\.venv\Scripts\python.exe -m ingestion.pipelines.ingest_jsonl data\synthetic\sample_documents.jsonl --processed-output data\processed\sample_chunks.jsonl --with-embeddings
```

The embedding model used for the processed preview is `hashing-384-v1`, a deterministic local hashing embedding. It is useful for development and testing without model downloads or paid APIs. A sentence-transformers or hosted embedding model can replace it later.
